
# User Stories Documentation

## ✅ App Administrator

## User Stories

- As an app administrator, I want to manage user roles and permissions so that I can control access securely.
- As an app administrator, I want to monitor system health and usage so that I can ensure optimal performance.
- As an app administrator, I want to configure integrations with Microsoft 365 services so that the app works seamlessly.

## Acceptance Criteria

- Admin dashboard displays user list with role assignment options.
- Role-based access control is enforced across all features.
- System health metrics (uptime, errors) are visible in real time.

## ✅ Content Editor

## User Stories

- As a content editor, I want to upload and update course materials so that learners always have current content.
- As a content editor, I want to schedule content publishing so that updates go live at the right time.
- As a content editor, I want to preview content before publishing so that I can ensure quality.

## Acceptance Criteria**

- Editors can upload PDFs, videos, and links via a web interface.
- Scheduled publishing dates trigger automatic content updates.
- Preview mode reflects final layout and formatting

## ✅ **Course Participant**

### ✅ **Course Participant**

**User Stories**

- As a course participant, I want to browse available courses so that I can choose relevant training.
- As a course participant, I want to track my progress so that I know how far I’ve come.
- As a course participant, I want to receive a certificate upon completion so that I can showcase my achievement.

## Acceptance Criteria

- Course catalogue displays categories and skill levels.
- Progress bar updates after each module completion.
- Certificates are generated automatically after passing all modules

## ✅ **HR Manager**

### ✅ **HR Manager**

**User Stories**

- As an HR manager, I want to initiate onboarding workflows so that new hires are set up quickly.
- As an HR manager, I want to track onboarding progress so that I can report to leadership.
- As an HR manager, I want to plan recruitment based on workforce gaps so that I can meet future needs.

**Acceptance Criteria**

- Onboarding form triggers automated tasks in Power Automate.
- Dashboard shows onboarding status by department.
- Recruitment needs auto-generate from leave and exit data.[3](<https://365evergreen.sharepoint.com/sites/>

## ✅ **Senior Managers**

### ✅ **Senior Managers**

**User Stories**

- As a senior manager, I want to view team training progress so that I can identify skill gaps.
- As a senior manager, I want to access compliance reports so that I can ensure regulatory requirements are met.
- As a senior manager, I want to approve high-level content changes so that governance is maintained.

**Acceptance Criteria**

- Training dashboard displays completion rates by team.
- Compliance reports are exportable in PDF format.
- Approval workflow requires senior manager sign-off before publishing sensitive content
